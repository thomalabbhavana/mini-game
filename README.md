# Tic Tac Toe Game

## Project Description

Tic Tac Toe is a console-based two-player mini game developed using C++. The project demonstrates fundamental programming concepts such as arrays, loops, functions, conditional statements, and user input handling.

## Key Features

* Two-player gameplay
* Dynamic 3×3 game board
* Player X and Player O
* Win detection
* Draw detection
* Invalid input handling
* Occupied position checking
* Replay option

## Technologies Used

* C++
* Arrays
* Loops
* Conditional Statements
* Functions

## Concepts Used

* One-dimensional and two-dimensional arrays
* `for` and `while` loops
* `if-else` statements
* Functions
* Character variables
* User input and output

## Expected Outcome

The application provides an interactive Tic Tac Toe game where two players can make moves, view the updated game board after every move, and receive the result when a player wins or the game ends in a draw. Players can also choose to replay the game.

## How to Run

1. Download or clone the repository.
2. Open `TicTacToe.cpp` using a C++ compiler.
3. Compile the program.
4. Run the executable.
5. Enter positions from 1 to 9 to play the game.

## Game Instructions

The board positions are:

```
1 | 2 | 3
---+---+---
4 | 5 | 6
---+---+---
7 | 8 | 9
```

Player X starts the game.

Players take turns entering the position where they want to place their symbol.

The first player to get three symbols in a row, column, or diagonal wins.

If all positions are filled without a winner, the game is declared a draw.
